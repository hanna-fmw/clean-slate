reclaim

Disk + memory janitor. Runs automatically every 3 days.

reclaim cleanScan + tickbox dialog (Cancel / Ask Claude / Continue)
reclaim clean -yHeadless: low-risk set only (.next, DMGs, Docker, npm, Claude VM)
reclaim scanNotify how much is cleanable, delete nothing
reclaim dryPrint the plan to stdout, delete nothing
reclaim historyPast runs + space freed
reclaim stats · trendLifetime totals; regrowth forecast
reclaim topBiggest space users on disk
reclaim ram · monitorMemory hogs / text Activity Monitor
reclaim monitor --freePick heavy apps to quit
reclaim doctorSelf-check (install, PATH, schedule, deps)
reclaim statusSchedule state, last run, free space
reclaim enable · disableToggle the 3-day schedule

Source at ~/Documents/utilities/reclaim/.
