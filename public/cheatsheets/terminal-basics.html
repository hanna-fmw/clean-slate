Terminal Basics

Typing tilde (~) on a Swedish keyboard
Alt + ¨ → SpaceHold Alt, press ¨, release, then press Space. Produces ~. In the shell ~ expands to your home directory.
cd ~/DocumentsJump straight to your Documents folder from anywhere
cd ~ or just cdGo home
Move around the filesystem
pwdPrint working directory (where am I?)
lsList files in current dir
ls -laList everything, including hidden files, with details
cd fooGo into folder foo
cd ..Go up one folder
cd -Go back to the previous folder you were in
open .Open the current folder in Finder
Work with files
mv a.txt b.txtRename a.txt to b.txt
mv file ~/Documents/Move file into Documents
cp a.txt b.txtCopy a.txt to b.txt
cp -r foo barCopy folder foo (and contents) to bar
rm fileDelete a file (no trash, gone immediately)
rm -rf folderDelete a folder and everything inside. Dangerous - check twice.
mkdir new-folderCreate a folder
Read a file
cat filePrint the whole file to the terminal
less fileOpen a paged view (better for long files). Then: q quit, /word search, space = next page.
head fileFirst 10 lines
tail fileLast 10 lines
tail -f log.txtFollow a log file live as it grows. Ctrl + C to stop.
Edit a file (nano, vim) and how to get out

You'll usually end up in one of these editors when git asks you to write a commit message, or when you run nano file / vim file yourself.

nano (easy) Open: nano file.txt
Type normally. Save + exit: Ctrl + X, press Y to confirm, then Enter.
Exit without saving: Ctrl + X, then N.
vim (harder) Open: vim file.txt
To start typing: press i (insert mode).
To stop typing: press Esc.
Save + quit: type :wq then Enter.
Quit without saving: type :q! then Enter.
Stuck Ctrl + C usually cancels. Ctrl + D sends end-of-input.
Find things
find . -name "*.md"Find all .md files under the current folder
grep -r "word" .Search for word in every file under the current folder
which commandWhere is this command installed?

Works in any macOS terminal (Terminal.app, iTerm2, Warp, VS Code / Cursor / Claude Code shells).
