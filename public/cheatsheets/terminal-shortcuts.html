Terminal Shortcuts

Move around the line

Opt + ← / →Jump word left / right
Cmd + ← / →Jump to beginning / end of line

Delete

Ctrl + UDelete from cursor to start of line
Ctrl + KDelete from cursor to end of line
Ctrl + WDelete word before cursor
Opt + DeleteDelete word before cursor
Ctrl + YPaste (yank) last deleted text

Typing tilde (~) on a Swedish keyboard

Alt + ¨ → SpaceHold Alt, press ¨, release, then press Space. Produces ~. In the shell ~ expands to your home dir (~/ = your user folder).

Works in Terminal, iTerm2, and the shells inside VS Code / Cursor / Claude Code.
