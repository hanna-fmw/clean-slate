# Ops Dashboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static Next.js dashboard at ops.hosk.app showing all personal projects, service accounts, and infrastructure in three scannable tabs.

**Architecture:** Next.js 16 app with static generation — data read from `config/data.json` at build time, no server or database. Server components pass rendered tab content as children to a single client component (TabsNav) that handles tab switching. Each row is an expandable client component.

**Tech Stack:** Next.js 16 (App Router, static generation), TypeScript, shadcn/ui (Tabs, Collapsible, Badge), Tailwind CSS, pnpm, Vercel deployment.

```ts
export function isStale(lastReviewed: string, thresholdDays = 90): boolean {
  const last = new Date(lastReviewed)
  const now = new Date()
  const diffDays = (now.getTime() - last.getTime()) / (1000 * 60 * 60 * 24)
  return diffDays > thresholdDays
}
```
