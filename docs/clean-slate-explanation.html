Totally fair - these are separate concepts that all sound similar. Let me untangle them calmly. It's simpler than it feels.

1. The launchd job

launchd is macOS's built-in task scheduler (the Mac equivalent of a cron job). You have one registered as com.hosk.clean-slate-sync, and it's currently loaded and active. It runs scripts/auto-sync.sh every 6 hours (21600 seconds). That script regenerates config/data.json from your CLEAN-SLATE.md files. It's native to your Mac - nothing in the cloud.

2. Why no database is needed

Here's the key: the reading does not happen live from your .md files. The flow is:

  • Every 6 hours, the launchd job reads all your CLEAN-SLATE.md files and bakes them into one file: config/data.json.
  • That data.json gets committed and ends up deployed with the app.
  • When the live site renders, it just imports that one JSON file. The data is "frozen" into the deployment.

So the website never touches your Mac or your .md files - it only reads the snapshot that was baked in at deploy time. A database is for data that changes from user actions (logins, form submits, edits in the app). Clean Slate has none of that - it's read-only and the content only changes when you edit a markdown file and re-sync. That's why a static JSON file is perfect and a database would be overkill. (Trade-off: edits only show up live after a sync + redeploy, not instantly. For a personal dashboard, that's fine.)

3. Cloudflare: Tunnel vs Zero Trust vs Access

These get conflated constantly. Quick map:

  • Cloudflare Zero Trust = the umbrella product/dashboard name. Not a feature itself, just the platform that contains the others.
  • Cloudflare Access = the password/login gate. This is the thing you want - it puts a login screen in front of a site. (Lives inside Zero Trust.)
  • Cloudflare Tunnel = a different tool, for exposing something running on a private machine (like your homelab) to the internet without opening ports. You do NOT need this - Clean Slate is already public on Vercel, not on a private machine.

So for your goal: you only need Cloudflare Access. Ignore Tunnel entirely.
